Connect the planner to Mealie

This app needs to know where your Mealie is and how to sign in. These are set as environment variables on the container, not on this page.

  • MEALIE_BASE_URL The address of Mealie as this app can reach it, for example http://mealie:9000. {% if 'MEALIE_BASE_URL' in config_missing %}Not set.{% else %}Set.{% endif %}
  • MEALIE_TOKEN An API token: in Mealie open your profile, choose API Tokens and create one. {% if 'MEALIE_TOKEN' in config_missing %}Not set.{% else %}Set.{% endif %}

With Docker Compose, put them in the .env file next to docker-compose.yml (or under environment:), then restart the container. Optional extras: ANTHROPIC_API_KEY for generating recipes and APP_PASSWORD to require a login.
